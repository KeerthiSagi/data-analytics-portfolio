# Sample data

`messy_customers.csv` is a **synthetic** customer table made for demonstrating REFINE. Every name, email address, and value is invented.

The file is generated by [`generate_messy_customers.py`](generate_messy_customers.py) with a fixed seed. Running the script again reproduces the committed file byte for byte, and a test checks this.

```bash
python sample_data/generate_messy_customers.py
```

## Shape

500 data rows × 9 columns, UTF-8, comma-delimited, with a clean header. The file parses with no load notes. All of its problems are in the values, so later phases can find and fix them.

## Defects included on purpose

| Area | What was injected |
|---|---|
| Exact duplicates | 12 rows are verbatim copies of earlier rows |
| Key duplicates | 8 more rows reuse an existing `customer_id` with a different email case, name casing, and `is_active` value. In total, 20 rows repeat an ID. |
| Missing-value markers | `""`, `NA`, `N/A`, `null`, `-` in `email`, `signup_date`, `age`, `annual_spend` |
| Mixed date formats | `2024-01-05`, `01/05/2024` (month first), `05.01.2024` (day first), `Jan 5, 2024` |
| Numbers stored as text | `age` mixes `43`, `43.0`, `unknown`. `annual_spend` mixes `1234.50`, `$1,234.50`, `1,235`. |
| Inconsistent text | `country` spellings (`USA`, `usa`, `U.S.`, ` United States`), segment casing and double spaces, name casing and stray spaces, upper-case emails |
| Inconsistent booleans | `is_active` uses `Yes/No`, `Y/N`, `true/false`, `1/0` |
| Outliers | 4 impossible ages (`230`, `-3`, `999`, `150`) and 3 extreme `annual_spend` values |

The exact counts are defined in `EXPECTED` in the generator.
