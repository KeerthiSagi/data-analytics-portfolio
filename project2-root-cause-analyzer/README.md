# CAUSE — Metric Drop Root Cause Analyzer

A Streamlit app that compares business metrics between two periods and breaks the change down by market, region, category and customer segment.

**Live app:** https://data-analyst-portfolio-yictmcakk4rypw8ulkd85s.streamlit.app/

## Overview

When revenue, profit or margin moves from one period to the next, CAUSE shows where the change came from. You pick an analysis period and a comparison period, and the app calculates each group's contribution to the change. Contributions are checked to add up exactly to the total change.

CAUSE describes where a change is concentrated. It does not establish why it happened; its findings are starting points for further investigation.

## Features

**Metric Overview**
- Revenue, profit, distinct orders and profit margin compared with the previous period or the same period last year
- Monthly revenue and profit trend with both periods highlighted
- Breakdowns by market, category and customer segment

**Root Cause Investigation**
- Contribution of each group to the change in revenue, profit, orders or margin, shown as a waterfall chart and a ranked table
- Profit margin changes split into a rate effect (the group's own margin changed) and a mix effect (its share of revenue changed)
- Two-level drill-down, for example market and then category, where the child rows add up to their parent

**Revenue Driver Analysis**
- Revenue change split into an order volume effect and an average order value effect
- Revenue bridge chart and monthly trends for orders and average order value

**Investigation Report**
- Summary of the current investigation with top positive and negative contributors
- Downloads: KPI comparison, contributions and findings as CSV, and the full report as Markdown

All pages share the same sidebar: period type (month, quarter, year or custom range), comparison type, and filters for market, region, category and segment. Findings on each page are generated by fixed rules from the calculated numbers, such as flagging changes of 10% or more.

## Dataset

The app uses the Global Superstore file from Project 1 (`project1-atlas-analytics/data/Global_Superstore.xlsx`):

- 51,290 order line items, January 2011 to December 2014
- 25,754 distinct orders
- 7 markets, 18 market-specific regions, 3 categories, 3 customer segments

Some order IDs in the dataset are reused by different customers or on different dates (660 of them), so CAUSE identifies an order by order ID, customer ID and order date together. The data is validated when it loads, and a different copy of the file can be used by setting `CAUSE_DATA_PATH`.

## Run Locally

```bash
cd project2-root-cause-analyzer
pip install -r requirements.txt
streamlit run app_root_cause.py
```

## Tests

```bash
pip install -r requirements-dev.txt
pytest
```

Run from the `project2-root-cause-analyzer` folder. The suite has 228 tests covering data loading, period selection, KPI calculations, contribution and decomposition math (including hand-worked examples), the rule-based findings, exports, and page rendering with Streamlit's `AppTest`. Reconciliation is also tested on the real dataset: for every metric and dimension, the group contributions add up to the total change.
